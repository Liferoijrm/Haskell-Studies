# 🚀 Haskell Studies

Repositório dedicado ao estudo da linguagem Haskell, focado em entender o paradigma funcional e suas estruturas de dados.

## 📂 Estrutura do Projeto

Os arquivos estão organizados de acordo com o progresso nos slides e tópicos abordados em aula, com anotações e resoluções de exercícios:

- `slide1___HaskellBasico`:  Sintaxe básica, definição de funções, recursão, expressões e tipos fundamentais
- `slide2___Listas`: Estrutura de listas, operações básicas e compreensão de listas (list comprehension)
- `slide3___generalizacao`: Funções de alta ordem (map, foldr, filter) e introdução a polimorfismo paramétrico
- `slide4___composicaoAplicacaoParcial`: Composição de funções, aplicação parcial e currying como modelo de avaliação funcional
- `slide5___tiposAlgebricos`: Tipos algébricos de dados, polimorfismo de tipos, classes básicas (Eq, Ord, Show), instâncias e derivação, uso de Maybe para tratamento de erro e funções parciais
- `slide6___TypeClasses`: Type classes avançadas, restrições (constraints), hierarquia e relações entre classes de tipos

E de acordo com as listas de exercícios passadas na disciplina:

- `lista`:  Resolução da lista de exercícios pré-prova, que aborda todo o conteúdo
- `prova`: Resolução de uma prova antiga da disciplina

## 🛠️ Como executar

Para rodar os arquivos, você precisará do **GHCi** (Glasgow Haskell Compiler interactive).

1. Abra o terminal na pasta do arquivo desejado.
2. Digite: `ghci nome_do_arquivo.hs`
3. Chame as funções diretamente no prompt.
